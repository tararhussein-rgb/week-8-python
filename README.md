# Personal Mini-Toolkit

A menu-driven Python command-line application built as the final project for the Python programming course. It bundles three handy utilities into one seamless interactive program.

## Features
1. **Number Guessing Game**: Tests your luck against a randomly generated number.
2. **Interactive To-Do List**: Dynamically adds and removes tasks while running.
3. **Tip & Bill Splitter**: Calculates shared expenses quickly and accurately.

## How to Run
1. Ensure Python is installed on your machine.
2. Clone this repository or download the files.
3. Open your terminal in the project directory and run:
   ```bash
   python toolkit.py
